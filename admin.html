Mot de passe d'accès à ce panneau

Stocké uniquement sous forme de hash SHA-256, dans le stockage local de ce navigateur. Changer de navigateur ou d'appareil demandera d'en redéfinir un.

Chiffrement de la section « cours »

⚠️ Ce chiffrement dissuade la copie triviale du contenu (bots simples, robots d'indexation, curieux consultant data.json). Comme l'application est 100% cliente (sans serveur), la clé de déchiffrement doit être présente dans app.js pour que l'app fonctionne hors ligne — ce n'est donc pas un secret absolu face à quelqu'un qui inspecte le code source. Détails dans README.md.
ℹ️ Si vous modifiez cette clé, reportez-la exactement dans app.js, ligne const APP_DECRYPT_PASSPHRASE = "…";, sans quoi l'application ne pourra plus afficher les cours.

Typographie

Par choix technique, l'application utilise des polices « système » plutôt que des polices web téléchargées : elles s'affichent instantanément, fonctionnent hors ligne dès la première visite et couvrent nativement les 9 alphabets pris en charge (latin, cyrillique, arabe, chinois…).

    Médiathèque

    Photos, audio, vidéos locales et vidéos YouTube intégrées. Tout média ajouté ici devient disponible dans l'éditeur de cours (bouton « 🖼️ Média ») et, si la catégorie est « Guide de l'Allemagne », apparaît automatiquement dans une galerie sur cette page côté application.

    ℹ️ Il existe aussi une méthode sans data.json : déposez directement sur GitHub un fichier nommé galerie-photo-1.jpg, galerie-photo-2.jpg… ou galerie-video-1.mp4, galerie-video-2.mp4… à la racine du dépôt, et il apparaît automatiquement dans l'onglet « Galerie » de l'application, sans export ni téléversement de data.json. Détails complets dans README.md.
